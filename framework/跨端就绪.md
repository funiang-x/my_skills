# 跨端就绪 —— 任何 agent 靠什么进入这套流程

> 本文件是 [`骨架总则.md`](骨架总则.md) §2 的「跨端契约」。
> 前提：**不依赖任何平台特性**——不依赖钩子、不依赖 MCP、不依赖某家的自动触发、不依赖云端配置。

## 1. 只依赖三件事

任何 agent 都会做、且不挑平台的只有三件：

1. **读工作区根的文件**（`AGENTS.md` / `CLAUDE.md` / `.trae/rules/`）
2. **被那扇门指向另一个文件**（薄转发，正文只有一处）
3. **跑命令行**

所以整套流程的入口就是：**工作区根一扇薄门 → `ROUTE.md` → 该任务类型的全部 skill。**

## 2. 薄门（三扇，正文都不在这里）

门里**只写三句**，不装规则：

```
[MUST] 开工前置：任何任务动手前，先读 <库路径>/ROUTE.md，按其 §1 走四步
       （拿证 → 判类 → 装 skill → 读参考），先输出 [ROUTE] 声明再干活。
```

| 门 | 服务谁 |
|---|---|
| `AGENTS.md` | 通用（Codex / DSH / 多数 CLI agent） |
| `CLAUDE.md` | Claude 系 |
| `.trae/rules/project_rules.md` | Trae |

**正文只有一份**：规则在 `ROUTE.md`，阶段在 `WORKFLOW.md`，契约在 `framework/`。
门里复述规则 = 迟早和正本打架。

**铺门用命令，不靠手抄**（避免路径写错、避免漏一个客户端）：

```
python tools/skillman.py doors <工程路径>     # 从 templates/ 铺三扇薄门
python tools/skillman.py check <工程路径>     # 验三扇门是否指向库正本
```

## 3. 一条硬约束：只有库根一级会被发现

各客户端（`~/.agents/skills`、`~/.trae-cn/skills`、`~/.codex/skills`）都**只扫库根一级目录**
里的 `SKILL.md`。嵌套目录里的 `SKILL.md` **不会被任何客户端发现**。

所以：
- **skill 必须住库根一级**（`stm32-hal-cli-flow/`，不是 `adapters/stm32/`）
- `framework/` 这类纯文档目录不需要被发现——它由 `ROUTE.md` 和门指向就够

## 4. 开工证（发证 → 只打印）

`python tools/preflight.py <任务类型>` 打印该类任务**必读条款正文**，然后按 §2 输出 `[ROUTE]` 声明。

**状态文件写在 `<工作区>/.ai-skills-state/`，不写用户目录。**

为什么改：原来写在工作区外，在受限文件沙箱下会被**直接拒绝**——于是"拿不到证"和
"环境不让写"混成同一个失败，看起来像违规。写在工作区内，沙箱内外都能跑。

## 5. 可选的强制（装了更好，不装不影响）

`hooks/skill_gate.py` 是 `PreToolUse` 钩子：没拿开工证就改本库 / 跑库内脚本会被拦下。

**它是可选增强**：只有支持钩子的客户端能装。不装时流程照跑，只是少了机器强制。

## 6. 已知弱点（明写，不藏）

| 弱点 | 后果 | 缓解 |
|---|---|---|
| **没有强制力** | "AI 有没有真去读 `ROUTE.md`"靠**你看声明**，不靠机器拦 | 门写显眼 + `skillman.py check` 验门 + 收工自检四问 |
| **声明可以敷衍** | AI 可能贴了 `[ROUTE]` 但没真装 skill | 收工自检第 1 问："声明里列的 skill，真的都装载并按其要求做了吗" |
| **各家扫描规则可能变** | 今天库根一级够用，某客户端改深扫/浅扫就失效 | 加新客户端时照 [`适配层契约.md`](适配层契约.md) §0 与 `agent-skill-wiring` 复验一次 |
| **多端标题不一致** | 同一个 skill 在不同客户端显示名不同 | 无解，属客户端行为；正本一致即可 |

这些是**选了"不依赖平台特性"之后必须付的代价**，不是待修的 bug。要强制力就得绑平台，
那就退回"换个客户端就失效"——与目标冲突，不划算。

## 7. 收工自检（弱门的补偿）

每个任务收尾问四句：

1. 声明里列的 skill，**真的都装载并按其要求做了吗**？
2. 声明里列的文档，**真的都读了吗**（还是只在声明里写了路径）？
3. 中途任务类型变过吗？**变了而没补声明 = 违规**。
4. 动手前**拿开工证了吗**？期间**改过 skill 吗**（改过则旧证作废，要重跑 `preflight.py`）？
