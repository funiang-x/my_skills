## 2. 两条 EDA 链路，各有分工（**都在跑，别互相替代**）

本机**同时有两条**通往 EasyEDA 的路，用途不同。两者都实测在跑（2026-10-01）：

| | **链路 A：typed actions（首选）** | **链路 B：API 桥（逃生口）** |
|---|---|---|
| 入口 | `easyeda` CLI（`C:\Users\funiang\.local\bin\easyeda.exe`） | HTTP/WebSocket，`scripts/bridge-server.mjs` |
| 进程 / 端口 | `easyeda` daemon（pid 3520）· **60832–60841** | `node`（pid 10116）· **49620** |
| 能力面 | **192 个 typed actions**（`system.health` / `sch.*` / `pcb.*` / `doc.*` …），带域与阶段、有校验 | 直接调官方 `eda.*` API，**未类型化** |
| 什么时候用 | **默认用它** —— 落件、连线、DRC、连接回读、块实例化 | 只在 typed action 缺失时当逃生口（skill 要求：先把它标 `planned`/`unsupported`，别用 GUI 兜底） |
| 风险 | 低（有校验、可对账） | 高（任意 JS 打到 EDA 上，绕过了校验） |

**两者都从用户已打开的 EDA 现场取数**，所以现场前提是共用的（见 §3）。

> ⚠️ **别搞成对立**：不是"用 A 就不用 B"，也不是"B 是旧东西该删"。
> A 是**主路**，B 是**补路**。用户自己的口径：两个端口都是用来画原理图的。
> 判据是「这条动作 A 有没有类型化实现」：有 → 走 A；没有 → 按 skill 的规矩标 unsupported 或走 B。

⚠️ **点名一条硬规则**（`easyeda-agent` skill 正文定的，不是本文件发明的）：
> 现场操作使用用户已打开的**内置浏览器 Web EDA**；**禁止启动或切换到 EasyEDA 桌面版**。

G2026 的历史文档里出现过 `lceda-pro.exe`（桌面版）与端口 49620 并记的写法 —— 那是把
"桥的端口"和"桌面版客户端"混在一起记的。**端口 49620 是 `bridge-server.mjs`，不是桌面版**
（实测进程命令行：`node ...\.zcode\skills\easyeda-api\scripts\bridge-server.mjs`；
而 `.zcode\skills` 是指向 `~/.ai-skills` 的 Junction，即**同一份 skill**）。

## 3. 现场前提（缺了就别谈落图）

| 前提 | 判据 | 缺了怎么办 |
|---|---|---|
| daemon 在跑（链路 A） | `easyeda daemon health` 退 0 | 起它：`easyeda daemon start --auto-update-skill=false`（**必须关 skill 自动同步**，否则顶掉本库接线） |
| 桥在跑（链路 B） | 端口 **49620** 有 `node` 在听 | 起 `bridge-server.mjs` |
| EDA 窗口已连接 | `easyeda health` 里出现 `easyedaVersion` / `connectorVersion` / `lastSeen` | 打开**内置浏览器 Web EDA**（**不是桌面版**） |
| **有打开的工程与文档** | `easyeda project doc` 返回文档，而非 `No active document` | **人工**在 EDA 里打开工程 + 原理图页。AI 无法替你开 |

**最后一条是硬前置**：`No active document` / `No current project is open` 时，
所有 `sch` 动作都无处落地 —— 这不是 bug，是"还没开图"。

### connector DEGRADED 怎么处理

提示长这样：`connector looks DEGRADED under load (recent EFFECT failure rate 100%, N consecutive failures)`。

处置顺序（照它自己的建议）：
1. **插一次轻读**（如 `easyeda doc`）让它自己恢复心跳
2. 仍不行 → `easyeda doc reload`
3. 再不行 → 在 EDA 侧重载连接器扩展

**别把它当成"固件/图有问题"** —— 这是连接器负载态，与设计内容无关。

## 4. 电路块库（离线可用，不必开 EDA）

```powershell
easyeda blocks ...
```

**内嵌在二进制里**，不需要 daemon、不需要开 EDA、不需要 skill 文件。
含：CH340 USB-serial、ESP32 自动下载、XL1509 buck、SP3485 RS-485、CC1101 RF、microSD…
这些块的**内部拓扑固定**，可以逐字复制，只需把**边界网络（ports）**重绑到宿主设计。

⇒ 画常用外设时**先查块库**，别从零摆件 —— 这是 `easyeda-agent` skill 的"找相近样例"思路的落地。
