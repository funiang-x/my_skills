## 2. ⚠️ 两条 EDA 链路，别混（本机最易踩的坑）

本机**同时存在两条**通往 EasyEDA 的路，端口、端、工具全不一样：

| | **链路 A：`easyeda-agent`（本机新链，优先用）** | **链路 B：旧链（文档里还留着）** |
|---|---|---|
| 入口 | `easyeda` CLI（`C:\Users\funiang\.local\bin\easyeda.exe`） | 脚本 `eda_sch.py` / `audit_sch.py`（**已不在本机**） |
| 端口 | **60832–60841** | 文档记的是 **49620** |
| 端 | 用户已打开的**内置浏览器 Web EDA** | 文档记的是 `lceda-pro.exe`**桌面版** |
| 能力 | typed actions：`sch` / `pcb` / `doc` / `apply` / `health` / `blocks`… | 单点脚本 |
| 版本（2026-10-01） | daemon **v1.8.1**，connector **1.8.0**，EasyEDA Pro **4.1.60** | — |

**铁律（`easyeda-agent` skill 正文定的，不是我的偏好）**：
> 现场操作使用用户已打开的**内置浏览器 Web EDA**；**禁止启动或切换到 EasyEDA 桌面版**。

所以：**用链路 A，别照旧文档去连 49620 或 `lceda-pro.exe`** —— 那是另一条链的痕迹，
按它做会连不上或连错端。旧链的脚本在本机已不存在。

## 3. 现场前提（缺了就别谈落图）

| 前提 | 判据 | 缺了怎么办 |
|---|---|---|
| daemon 在跑 | `easyeda daemon health` 退 0 | 起它：`easyeda daemon start --auto-update-skill=false`（**必须关 skill 自动同步**，否则顶掉本库接线） |
| EDA 窗口已连接 | `easyeda health` 里出现 `easyedaVersion` / `connectorVersion` / `lastSeen` | 打开内置浏览器 Web EDA（**不是桌面版**） |
| **有打开的工程与文档** | `easyeda project doc` 返回文档，而非 `No active document` | **人工**在 EDA 里打开工程 + 原理图页。AI 无法替你开 |

**最后一条是硬前置**：`No active document` / `No current project is open` 时，
所有 `sch` 动作都无处落地 —— 这不是 bug，是"还没开图"。

### connector DEGRADED 怎么处理

提示长这样：`connector looks DEGRADED under load (recent EFFECT failure rate 100%, N consecutive failures)`。

处置顺序（照它自己的建议）：
1. **插一次轻读**（如 `easyeda doc`）让它自己恢复心跳
2. 仍不行 → `easyeda doc reload`
3. 再不行 → 在 EDA 侧重载连接器扩展

**别把它当成"固件/图有问题"** —— 这是连接器负载态，与设计内容无关。

## 4. 电路块库（离线可用，不必开 EDA）

```powershell
easyeda blocks ...
```

**内嵌在二进制里**，不需要 daemon、不需要开 EDA、不需要 skill 文件。
含：CH340 USB-serial、ESP32 自动下载、XL1509 buck、SP3485 RS-485、CC1101 RF、microSD…
这些块的**内部拓扑固定**，可以逐字复制，只需把**边界网络（ports）**重绑到宿主设计。

⇒ 画常用外设时**先查块库**，别从零摆件 —— 这是 `easyeda-agent` skill 的"找相近样例"思路的落地。
